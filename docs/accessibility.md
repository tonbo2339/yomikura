# アクセシビリティ (読みやすさ・使いやすさ)

ヨミクラで、文字の見えかた・操作のしやすさ・目に頼らない読みかたを調整できる設定をまとめます。

## 文字の見えかた

- **本文の文字** (設定 → 本文の文字): フォント (サイト標準・ゴシック・明朝)、文字サイズ (80〜250%)、行間を変えられます。100% は端末の標準の文字の大きさです。なろう・ハーメルン・カクヨムの本文と、オフラインで読むときに使われます。
- **テーマ** (設定 → テーマ): 自動 (端末の設定に合わせる)・ライト・ダークから選びます。ダークのときは、サイトの表示も暗くします。
- **縦書き** (設定 → 本文の文字): オフライン保存した作品の読み画面だけが縦書きになります。
- **ヘッダー・フッター・感想・おすすめなど**は、読書ページでは畳んであり、必要なときだけボタンで開けます (設定 → 話ページの下の欄)。画面の情報を減らしたいときに使えます。

## 操作のしやすさ

- **操作部分の大きさ** (設定 → 操作部分の大きさ): 小さめ・標準・大きめから選びます。リストなどのボタンやタブの大きさが変わります。
- 「戻る」や「削除」など、小さくなりがちなボタンは、押せる範囲を縦横 44px 以上にしてあります。
- **上部バー** (設定 → 上部バー): 再読み込みボタンなどの表示と、⋮ メニューに出す項目を選べます。使わない項目を減らして、押し間違いを減らせます。
- **動き**: ボタンの弾みや、確認中の本のページめくりなどの小さな動きは、端末の「アニメーションを減らす」(Android の設定 → ユーザー補助) をオンにすると止まります。

## 目を使わずに読む・手を使わずに読む

- **読み上げ**: 作品のページの ⋮ メニューの「読み上げ」で、開いている話の本文を Android の音声合成 (日本語の声) で読み上げます。速さを変えられ、声の種類は Android の設定の「音声合成の出力」で選べます。ルビは読みません。
- **自動スクロール**: ⋮ メニューの「自動スクロール」で、ページが自動で進みます。速さは変えられ、画面を触ると止まります。
- **音量キーでページ送り**: 音量の「下」で 1 画面下へ、「上」で 1 画面上へ進みます (設定 → 読書の補助)。

## スクリーンリーダー (TalkBack) について

- アイコンだけのボタンの多くには、読み上げ用の名前を付けてあります (検索・設定・メニュー・「後で読むに追加」など)。
- ただし、すべての画面で TalkBack を使って確かめたわけではありません。次の点は未対応または不十分です。
  - アプリのアイコンを選ぶ画面は、画像だけを並べているので、読み上げ用の名前がありません。
  - サイトの本文や画面は、各サイトの作りに従います。ヨミクラ側では直せません。
- 使いにくい点を見つけたら、[Issues](../../../issues) で教えてください。報告のしかたは [README](../README.md) にあります。
