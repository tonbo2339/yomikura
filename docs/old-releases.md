# 過去の版の変更点

GitHub の [Releases](../../../releases) には、最新の版だけを置いています。これより古い版の変更点を、ここに残します (APK は残していません。最新の版を使ってください)。新しい順です。

## v1.2.0 (2026-10-30)

1.1.2 からの主な変更です。

### 新しくできること

- **自由にフォントを追加**して本文を読むことができます
- **傍点や動く飾りなどを保存**して読むことができるようになりました
- **読み上げを、通知とロック画面から操作**できます (一時停止・再開・止める)
- **オフラインの保存を、自動で更新**できます。保存した作品に新しい話が出たら、更新の確認のあとで保存します
- **対応サイト以外のリンクの扱い**を選べます。既定のブラウザで開くか、アプリの中で開くかを、設定 → リンクの扱いで決められます
- **オフラインの読み画面**: 読み進めると、上下のバーが隠れます。戻す・タップで出ます
- **「話ページの下の欄」の見直し**: 畳むボタンの名前を、実際の中身に合わせました。設定の説明も、サイトごとの箇条書きに直しました
- そのほか、設定の並びと説明を整え、いくつかの不具合を修正しました

### 気をつけること

- 2 段階認証の鍵は、パスワードと同じくらい大事なものです。パスワードと同じ端末に置くと、2 段階認証の守りは弱くなります。自分だけが使う端末で使ってください。
- ヨミクラは、サイトの運営とは関係のない、非公式のアプリです。サイトの作りが変わると、自動で進まなくなることがあります。そのときは、認証コードを手で入れられます。
- 追加したフォントは、アプリの自動バックアップには入りません。端末を入れ替えたあとは、フォントを入れ直してください。入れ直すまでは、サイト標準の表示に戻ります。

## v1.1.2 (2026-10-24)

1.1.0 からの主な変更です。

### 新しくできること

- **なろうの 2 段階認証の自動入力**: なろうの認証アプリの設定の「セットアップキーで設定する」の画面で「ヨミクラにも登録する」を押すと、ログインのたびに、認証アプリのコードを自動で入れます (「認証」の画面から入力・送信まで)。1 回のログインにつき 1 回だけ動き、通らなかったときは止まります。鍵はこの端末の中で暗号化して保存します。設定 → ログインで、登録の状況の確認と削除ができます。登録のしかたは、[説明のページ](https://github.com/tonbo2339/yomikura/blob/main/docs/2fa-login.md) にまとめてあります
- **アプリの更新**: 設定の「アプリの更新」に、GitHub のリリースページへのリンクを置きました。過去の版や変更点は、そこで見られます

### 気をつけること

- 2 段階認証の鍵は、パスワードと同じくらい大事なものです。パスワードと同じ端末に置くと、2 段階認証の守りは弱くなります。自分だけが使う端末で使ってください。
- ヨミクラは、サイトの運営とは関係のない、非公式のアプリです。サイトの作りが変わると、自動で進まなくなることがあります。そのときは、認証コードを手で入れられます。

## v1.1.0 (2026-10-19)

1.0.0 からの主な変更です。

### 新しくできること

- **履歴**: 作品ごとに「12 / 120話」の話数、連載中・完結・短編の印、読みかけ (途)・未読 (未) の印を出します。長編は ▼ を押すと、日ごとに読んだ話と「続きから」「目次」のボタンが出ます。
- **リスト**: 読み具合の表示を作り直しました。連載の作品は「続きから」と「目次」を選べます。連載中・完結・短編は色で分けます。
- **更新の確認**: 確認画面 (Cloudflare など) が出たサイトは、画面に出してご自身で通せます。その間も、ほかのサイトの確認は続けます。
- **トップと作者ページ**: なろう・ハーメルンのトップと作者ページにも「後で読む」「ミュート」のボタンを付けました。
- **サイトの表示**: 読書ページ以外 (トップ・一覧・作者ページ) では、サイトのヘッダー・フッターを出すようにしました。
- **通知**: 通知のアイコンを本の形にし、選んだアプリのアイコンも添えます。
- **小さな動き**: ボタンの弾み、確認中の本のページめくり、統計の棒グラフなど (端末の「アニメーションを減らす」に従います)。
- **アプリの更新**: 更新の画面に、GitHub にある最新の版を出します。
- **変更点**: アプリを更新したあと、最初に開いたときに 1 回だけ、その版の変更点を出します。設定の「アプリの更新」でも読めます。

### 変わったこと

- 設定の「今すぐ裏で確認してみる」をなくしました (サイトへ続けてアクセスできてしまうため)。
- 読書位置は、リストの作品と、最近読んだ 100 作品の分を残します (10 作品から増やしました)。
- 目次を開いただけでは、履歴の時刻と順番を変えません。
- ハーメルンの「1 話から読む」は、作品のページを開きます (1 話が削除された作品で開けなかったため)。

### 直した不具合 (主なもの)

- まれに、保存データ (リスト・履歴・設定) 全体が空で上書きされうる不具合
- 特殊な文字を含む URL で、NSFW モードの判定がすり抜ける不具合
- 更新の確認で、アクセスを止められて休んでいるサイトに取りに行っていた不具合。途中で止まった確認のあと、10 分を待たずに確認し直せた不具合。画面での確認と裏での確認が重なることがあった不具合
- オフライン保存で、アプリが落ちたあと保存が再開しない、圏外で順番待ちが止まる、別の置き場所の挿絵 1 枚で同じサイトの保存がまとめて止まる、などの不具合
- 起動や復帰のときに、白い画面のままになる不具合
- なろうでログインしていないとき、作品名が「ログイン」になる不具合
- ハーメルンの短編で、作品名に話名が付く不具合
- 「すべてのデータを削除」のあとも、「復元前の状態に戻す」で消したデータを戻せた不具合
