# 18 歳以上の方向けの設定

**18 歳未満の人は、この機能を利用しないでください。**

ヨミクラは、初期状態では「NSFW モード」がオンで、成人向けのサイトへ一切アクセスしません。上部バーにも、リスト・履歴・ランキングにも出ません。

## 使えるようにする

1. 設定 → サイト → 「NSFW モード」をオフにします。
2. 「18 歳以上ですか？」と確認が出るので、18 歳以上の方だけ「18 歳以上です。オフにする」を押します。
3. 設定 → サイト → 表示するサイトで、使うサイトを選びます。

使えるようになると、ノクターンノベルズ・ムーンライトノベルズ・ミッドナイトノベルズが、小説家になろうと同じように使えます (リスト・更新の確認・オフライン保存など)。「なろう」のタブを素早く 2 回タップすると、成人向けのメニューが出ます。設定で、サイト名のタブにもできます。

## 気をつけること

- 各サイトの年齢確認は、ご自身で押してください。アプリは自動では押しません。なろう・ハーメルンの年齢確認にまだ答えていないときは、作品の判別 (成人向けかどうか、どのサイトか) へは進まず、答える画面へのご案内が出ます。「開く」を押して年齢確認に答えると、次にリストを開いたときから判別が進みます。更新の確認は、年齢確認の画面で止まって、答えを待ちます。
- 人前で使うときは、「NSFW モード」をオンにしてください。オンの間は、成人向けのサイトへのアクセスも、リスト・履歴・ランキングでの表示も、一切なくなります (データは消えません)。
- 外から成人向けのサイトのリンクが届いたときは、NSFW モードがオンなら、開かずに「後で読む」に入れるだけです。
