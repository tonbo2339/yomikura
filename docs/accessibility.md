# アクセシビリティ (読みやすさ・使いやすさ)

ヨミクラで、文字の見えかた・操作のしやすさ・目に頼らない読みかたを調整できる設定をまとめます。

## 文字の見えかた

- **本文の文字** (設定 → 本文の文字): フォント (サイト標準・ゴシック・明朝、追加したフォント)、文字サイズ (80〜250%)、行間を変えられます。100% は端末の標準の文字の大きさです。なろう・ハーメルン・カクヨムの本文と、オフラインで読むときに使われます。
- **好きなフォントを追加** (設定 → 本文の文字 →「フォントを追加」): 端末に保存した一般的な「.ttf」「.otf」「.ttc」のファイルを選ぶと、フォントの一覧に加わります。読みやすい書体や、好みの書体で読めます。
  - 名前は、フォントの中に入っている名前 (日本語の名前があればそれ) が初めに付きます。一覧の下の入力欄で変えて「保存」を押せます (Enter でも保存できます)。「削除」で消せます。
  - 追加できるのは 10 個まで、1 つ 40 MB までです。フォントではないファイルは、追加できません。
  - 選んだフォントは、サイトの本文と、オフラインで読むとき (縦書き含む) の両方に使います。フォントに入っていない字は、ゴシックで表示します。
  - フォントのファイルは、この端末の中だけに置き、外へは送りません。アプリにフォントは入っていません。使うフォントのライセンスは、ご自身で確かめてください。
  - 追加したフォントは、Android の自動バックアップや、設定の書き出しには入りません。端末を入れ替えたあとなどでフォントが無いときは、サイト標準の表示に戻ります。もう一度追加してください。「すべてのデータを削除」では、追加したフォントも消えます。
- **テーマ** (設定 → テーマ): 自動 (端末の設定に合わせる)・ライト・ダークから選びます。ダークのときは、サイトの表示も暗くします。
- **縦書き** (設定 → オフライン保存の設定 →「縦書きで表示」): オフライン保存した作品の読み画面だけが縦書きになります。文字の大きさとフォントは、「本文の文字」と共通です。
- **ヘッダー・フッター・感想・おすすめなど**は、読書ページでは畳んであり、必要なときだけボタンで開けます (設定 → 話ページの下の欄)。画面の情報を減らしたいときに使えます。

## 操作のしやすさ

- **操作部分の大きさ** (設定 → 操作部分の大きさ): 小さめ・標準・大きめから選びます。リストなどのボタンやタブの大きさが変わります。
- 「戻る」や「削除」など、小さくなりがちなボタンは、押せる範囲を縦横 44px 以上にしてあります。
- **上部バー** (設定 → 上部バー): 再読み込みボタンなどの表示と、⋮ メニューに出す項目を選べます。使わない項目を減らして、押し間違いを減らせます。
- **動き**: ボタンの弾みや、確認中の本のページめくりなどの小さな動きは、端末の「アニメーションを減らす」(Android の設定 → ユーザー補助) をオンにすると止まります。

## 目を使わずに読む・手を使わずに読む

- **読み上げ**: 作品のページの ⋮ メニューの「読み上げ」で、開いている話の本文を Android の音声合成 (日本語の声) で読み上げます。速さを変えられ、声の種類は Android の設定の「音声合成の出力」で選べます。ルビは読みません。画面を消したり、ほかのアプリに移ったりしても続き、通知とロック画面の「一時停止 / 再開」「止める」で操作できます (一時停止は、いまの段の先頭から読み直します。通知を出せないときは、画面を離れると止まります)。別のページへ移ると止まります。止めるときは、始めたときに出る「止める」か、⋮ メニューの「読み上げを止める」でも押せます (読み上げ中は上部バーを隠しません)。
- **自動スクロール**: ⋮ メニューの「自動スクロール」で、ページが自動で進みます。速さは変えられ、画面を触ると止まります。
- **音量キーでページ送り**: 音量の「下」で 1 画面下へ、「上」で 1 画面上へ進みます (設定 → 読書の補助)。

## スクリーンリーダー (TalkBack) について

- アイコンだけのボタンの多くには、読み上げ用の名前を付けてあります (検索・設定・メニュー・「後で読むに追加」など)。
- ただし、すべての画面で TalkBack を使って確かめたわけではありません。次の点は未対応または不十分です。
  - アプリのアイコンを選ぶ画面は、画像だけを並べているので、読み上げ用の名前がありません。
  - サイトの本文や画面は、各サイトの作りに従います。ヨミクラ側では直せません。
- 使いにくい点を見つけたら、[Issues](../../../issues) で教えてください。報告のしかたは [README](../README.md) にあります。
